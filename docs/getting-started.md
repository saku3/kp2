# Getting Started

まず現在のディレクトリを確認します。

```bash
pwd
```

次にファイル一覧を確認します。

```bash
ls -la
```

複数行のコマンドもそのまま実行できます。

```bash
for i in 1 2 3; do
  echo "hello $i"
done
```

**Insert** は入力だけしてEnterを押しません。編集してから実行したいときに使います。

```sh
echo "edit me before running"
```

`bash` / `sh` / `shell` 以外のコードブロックには Run ボタンは付きません。

```json
{ "note": "this is not runnable" }
```

```sh
uname -a
```
